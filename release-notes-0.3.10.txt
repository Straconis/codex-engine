Search now finds your own edits. When you correct a page by hand, searching finds the words you wrote instead of the old text. Undoing an edit makes search find the original text again. Edits you saved before this version are added to search the first time you open the app.
Safer AI formatting for numbered lists and roll tables. Before, the AI was allowed to drop any line that was just a number, because it looked like a page number. A roll table with an entry number on its own line could lose that number. Now only a number on the first or last line of a section can be dropped as a page number.
