Safer with your books and edits. Two PDFs with the same file name added at the same moment no longer overwrite each other. If a book's PDF is replaced by a shorter one, your hand edits and AI versions on the missing pages are kept instead of being deleted. Removing a book while one of its pages is being AI formatted no longer shows an error. A file that isn't really a PDF is refused straight away, and a full disk is reported clearly.
Your hand edits are safer in the reader. "Show page" in the AI progress window now asks before throwing away an unsaved edit, and you can no longer start editing (or save) while the next page is still loading, which could put an edit on the wrong page.
Updates: the app now closes only when the updater has really started. Before, it closed even when the release had no installer for your computer. Clicking Update twice no longer starts two downloads, the updater shows a message if the installer can't start, and update messages appear in Settings > Updates only.
Ollama: on Linux, the Ollama that Codex Engine starts no longer stops right after starting. Installing Ollama or plugging in the model drive is noticed without restarting the app. Saving Settings no longer restarts Ollama (and cuts off a running format or download) when only the model changed. Saving any setting no longer erases a saved Ollama location on a drive that is unplugged right now.
Search lists each page once, a search typed while another is still running can't be overwritten by the older answer, "Clear" also removes the old highlighting, and odd characters in a search no longer cause an error.
Smaller fixes: Escape and the arrow keys no longer act on the reader behind Settings or other windows, the "Changes" view no longer claims every word is the same when the AI version is outdated, error messages are readable instead of "[object Object]", two imports at once no longer mix their progress, and a book that can't be re-read is no longer re-read on every page view.
